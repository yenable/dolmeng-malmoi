# 사전 PDF 넣는 곳

원본 PDF 3개를 아래 **이름 그대로** 바꿔서 이 폴더에 넣어 주세요.
한글 파일명과 공백은 배포 환경에 따라 경로 오류가 나므로 영문 이름을 씁니다.

| 원본 | 이 폴더에 넣을 이름 | 쪽수 |
| --- | --- | --- |
| 1부 고유어.PDF | `book1-goyueo.pdf` | 17 |
| 2부 방언.PDF | `book2-jiyeogeo.pdf` | 15 |
| 3부 현대어.PDF | `book3-hyundaeeo.pdf` | 17 |

넣은 뒤 `npm run check:pdf` 로 쪽수를 확인할 수 있습니다.

PDF는 원본 그대로 사용합니다. 자르거나 재배치하거나 OCR로 다시 만들지 않습니다.
