# 돌멩민국 말모이 프로젝트

> 우리가 만든 사전 속에서 우리의 이야기를 발견합니다.
> 말을 모으고, 삶을 읽고, 우리를 발견하다.

초등학교 6학년 국어 수업용 **전자책 기반 우리말 탐구 웹사이트**입니다.
학생들이 직접 만든 〈2026 우리말 큰사전〉 세 권을 전자책으로 넘겨 보며,
말에 담긴 생각·문화·정체성을 발견하도록 돕습니다.

**최종 답안은 모두 종이 학습지에 손으로 씁니다.** 이 사이트에는 답안 제출 기능이 없습니다.

| 공간 | 역할 |
| --- | --- |
| 전자책 | 친구들이 만든 사전 원본을 읽는 곳 |
| 생각 도우미 | 스스로 생각하도록 질문·힌트·문장 틀을 주는 곳 |
| 종이 학습지 | 학생이 자신의 생각을 남기는 곳 |

## 1. 사전 PDF 넣기 (제일 먼저)

원본 PDF 3개를 `public/books/` 에 아래 이름으로 넣습니다.

| 원본 파일 | 넣을 이름 | 쪽수 |
| --- | --- | --- |
| `1부 고유어.PDF` | `public/books/book1-goyueo.pdf` | 17 |
| `2부 방언.PDF` | `public/books/book2-jiyeogeo.pdf` | 14 (원본 1쪽 삭제됨) |
| `3부 현대어.PDF` | `public/books/book3-hyundaeeo.pdf` | 17 |

> 한글 파일명과 공백은 배포 환경에 따라 경로 오류를 일으키므로 영문 이름으로 정리합니다.
> PDF 내용은 자르거나 재배치하지 않고 **원본 그대로** 사용합니다.

넣은 뒤 확인:

```bash
npm run check:pdf
```

## 2. 실행

```bash
npm install
npm run dev      # http://localhost:5173
```

PDF가 없으면 전자책 화면에 "사전 파일이 없거나 PDF로 읽히지 않습니다" 안내와
넣어야 할 파일 경로가 표시됩니다. 사이트가 깨진 것이 아닙니다.

## 3. 빌드 / 배포 (GitHub Pages)

```bash
npm run build    # dist/ 생성
npm run preview  # 빌드 결과 미리보기
```

- `vite.config.js` 의 `base: './'` 와 **HashRouter** 를 쓰기 때문에
  `https://아이디.github.io/저장소이름/` 같은 하위 경로에 올려도 그대로 동작합니다.
- 주소를 새로고침하거나 직접 입력해도 404가 나지 않습니다.
- `.github/workflows/deploy.yml` 이 들어 있어, `main` 브랜치에 push 하면 자동 배포됩니다.
  저장소 **Settings → Pages → Source** 를 `GitHub Actions` 로 한 번만 바꿔 주세요.

## 전자책 조작법

| 조작 | 방법 |
| --- | --- |
| 페이지 넘기기 | 화면 아래 ‹ › · 키보드 ← → · PageUp/PageDown · 모바일 좌우 스와이프 |
| 처음 / 마지막 | Home / End |
| 확대 · 축소 | + − 버튼 · 마우스 휠 · 트랙패드 · 두 손가락 핀치 · 더블클릭 |
| 원래 크기 | 되돌리기 버튼 또는 `0` |
| 확대 상태에서 이동 | 화면을 잡고 드래그 |
| 전체 화면 | 버튼 또는 `F` |
| 북마크 | 버튼 또는 `B` |
| 페이지 목록 | 상단 격자 버튼 → 썸네일을 누르면 바로 이동 |
| 한 쪽 ↔ 두 쪽 | 상단 책 모양 버튼 (PC 전용, 모바일은 항상 한 쪽) |
| 책장 넘김 끄기 | 하단 `책장 넘김` 버튼 |
| 생각 도우미 | 상단 전구 버튼 (`Esc` 로 닫기) |
| 수업 모드 | 상단 모니터 버튼 |

읽던 위치·북마크·한 줄 메모는 브라우저 `localStorage` 에만 저장됩니다.
로그인, 개인정보 입력, 서버 데이터베이스가 없습니다.

## 생각 도우미와 종이 학습지의 연결

| 패널 탭 | 종이 학습지 |
| --- | --- |
| 기억에 남는 말 | 학습지 1번 |
| 고유어 / 지역어 / 현대어에 담긴 이야기 | 학습지 2번 |
| 내 언어 | 학습지 2번 (자기 성찰) |
| 언어생활 다짐 | 학습지 3번 |

사전을 열면 그 사전에 맞는 탭이 자동으로 선택되지만, 학생이 언제든 다른 탭을 고를 수 있습니다.
힌트와 단계는 처음부터 전부 열리지 않고 **한 단계씩** 열립니다.

## 교사용 수업 모드

전자칠판·TV 화면용 모드입니다. 상단 모니터 버튼으로 켜고 끕니다.

- 메뉴를 최소화한 전체 화면 전자책
- 좌우에 큰 페이지 넘김 버튼
- `질문 띄우기` → 핵심 질문과 교사 발문을 화면 가운데에 큰 글씨로 표시
- `일반 모드` 버튼 또는 `Esc` 로 복귀

별도 비밀번호 없이 화면 모드만 바뀝니다.

## 사전에서 특정 쪽 지우기

원본에 잘못 들어간 쪽(빈 템플릿, 중복 등)을 영구히 빼야 할 때:

```bash
node scripts/_remove-page.mjs book2-jiyeogeo.pdf 1   # 1쪽 삭제, 나머지는 그대로 당겨짐
npm run check:pdf                                     # 바뀐 쪽수 확인
```

스크립트를 돌리기 전에 원본을 반드시 `originals/`(배포에 포함되지 않음)에 따로 복사해 두세요.
쪽을 지운 뒤에는 `src/data/books.js`와 `scripts/check-pdfs.mjs`의 `expectedPages`/`pages` 값도 함께 고쳐야 합니다.

## 접근성

- 모든 버튼에 이름(`aria-label`)이 있고 키보드로 조작됩니다.
- 본문 글자 대비를 충분히 두었고 글자를 작게 쓰지 않았습니다.
- `prefers-reduced-motion` 을 켠 기기에서는 책장 넘김과 전환 효과가 꺼집니다.
- PDF 로딩 중 안내와 실패 시 원인·해결 방법을 보여 줍니다.
